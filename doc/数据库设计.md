## 1. 表关系说明

```
sys_user（用户表）
  │
  ├──[1]── teacher_id ─────────────── class（班级表）
  │                                     │
  │                                     ├──[1]── class_id ─── student（学生表）
  │                                     │                        │
  │                                     │                        ├──[1]── student_id ─── attendance（考勤表）
  │                                     │                        ├──[1]── student_id ─── score（成绩表）
  │                                     │                        └──[1]── student_id ─── homework_submission（作业提交表）
  │                                     │
  │                                     ├──[1]── class_id ─── schedule（排课表）
  │                                     │                        │
  │                                     │                        └──[1]── course_id ─── course（课程表）
  │                                     │
  │                                     └──[1]── class_id ─── homework（作业表）
  │                                                              │
  │                                                              ├──[1]── course_id ─── course（课程表）
  │                                                              └──[1]── homework_id ─── homework_submission（作业提交表）
  │
  ├──[1]── teacher_id ─────────────── schedule（排课表）
  │
  └──[1]── teacher_id ─────────────── course（课程表，授课老师可为空）


关系速览：

| 主表 | 从表 | 关联字段 | 关系 |
|------|------|----------|------|
| sys_user | class | teacher_id | 一个老师负责多个班级 |
| class | student | class_id | 一个班级包含多个学生 |
| class | schedule | class_id | 一个班级有一张周课表 |
| course | schedule | course_id | 一门课出现在多个排课格中 |
| sys_user | schedule | teacher_id | 一个老师上多节课 |
| student | attendance | student_id | 一个学生有多条考勤记录 |
| class | attendance | class_id | 一个班级有多条考勤记录 |
| student | score | student_id | 一个学生有多条成绩记录 |
| course | score | course_id | 一门课有多条成绩记录 |
| class | homework | class_id | 一个班级有多条作业 |
| course | homework | course_id | 一门课对应多次作业 |
| homework | homework_submission | homework_id | 一次作业有多条提交记录 |
| student | homework_submission | student_id | 一个学生有多条提交记录 |
```

**说明**：箭头方向为 `[1]` 方指向 `[N]` 方，表示一对多关系。

## 2. 建表 SQL

### 2.1 用户表 sys_user

```sql
CREATE TABLE `sys_user` (
  `id`            BIGINT       NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
  `username`      VARCHAR(50)  NOT NULL                 COMMENT '用户名，用于登录',
  `password`      VARCHAR(255) NOT NULL                 COMMENT '密码，加密存储',
  `real_name`     VARCHAR(50)  NOT NULL                 COMMENT '真实姓名',
  `role`          TINYINT      NOT NULL DEFAULT 1       COMMENT '角色：1=管理员，2=教师',
  `phone`         VARCHAR(20)  DEFAULT NULL             COMMENT '手机号',
  `status`        TINYINT      NOT NULL DEFAULT 1       COMMENT '状态：1=正常，0=锁定',
  `locked_until`  DATETIME     DEFAULT NULL             COMMENT '锁定到期时间',
  `login_fail`    INT          NOT NULL DEFAULT 0       COMMENT '连续登录失败次数',
  `create_time`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`    TINYINT      NOT NULL DEFAULT 0       COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 2.2 班级表 class

```sql
CREATE TABLE `class` (
  `id`            BIGINT       NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
  `class_name`    VARCHAR(100) NOT NULL                 COMMENT '班级名称',
  `teacher_id`    BIGINT       NOT NULL                 COMMENT '负责老师ID，关联 sys_user.id',
  `description`   VARCHAR(500) DEFAULT NULL             COMMENT '班级描述',
  `create_time`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`    TINYINT      NOT NULL DEFAULT 0       COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='班级表';
```

### 2.3 学生表 student

```sql

  `id`            BIGINT       NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
  `student_no`    VARCHAR(50)  NOT NULL                 COMMENT '学号，唯一',
  `name`          VARCHAR(50)  NOT NULL                 COMMENT '学生姓名',

  `class_id`      BIGINT       NOT NULL                 COMMENT '所属班级ID，关联 class.id',
  `phone`         VARCHAR(20)  DEFAULT NULL             COMMENT '手机号',
  `address`       VARCHAR(200) DEFAULT NULL             COMMENT '家庭住址',
  `create_time`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`    TINYINT      NOT NULL DEFAULT 0       COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生表';
```

### 2.4 课程表 course

| 索引名 | 字段 | 索引类型 | 说明 |
|--------|------|----------|------|
| uk_username | username | 唯一索引 | 登录时按用户名查询，保证用户名唯一 |
| idx_role | role | 普通索引 | 下拉选择负责老师时按角色筛选教师 |

| idx_teacher_id | teacher_id | 普通索引 | 查询某老师负责的所有班级，或班级列表联表查老师姓名 |

### 3.3 student 学生表

| 索引名 | 字段 | 索引类型 | 说明 |
|--------|------|----------|------|
| uk_student_no | student_no | 唯一索引 | 保证学号唯一，新增/编辑时做重复校验 |
| idx_class_id | class_id | 普通索引 | 按班级筛选学生列表，仪表盘统计各班人数 |
| idx_name | name | 普通索引 | 按姓名模糊搜索时加速 LIKE 查询 |

### 3.4 course 课程表

| 索引名 | 字段 | 索引类型 | 说明 |
|--------|------|----------|------|
| idx_course_name | course_name | 普通索引 | 按课程名称搜索 |
| idx_teacher_id | teacher_id | 普通索引 | 查询某老师教授的课程 |

### 3.5 schedule 排课表

| 索引名 | 字段 | 索引类型 | 说明 |
|--------|------|----------|------|
| uk_class_day_period | class_id, day_of_week, period | 唯一索引 | 同一班级同一时间（星期+节次）只能安排一门课 |
| idx_teacher_id | teacher_id | 普通索引 | 校验老师时间冲突：查询某老师某一时间是否已有课 |

### 3.6 attendance 考勤表

| 索引名 | 字段 | 索引类型 | 说明 |
|--------|------|----------|------|
| uk_student_date | student_id, attendance_date | 唯一索引 | 同一学生同一天只能有一条考勤记录 |
| idx_class_date | class_id, attendance_date | 普通索引 | 按班级+日期范围查询考勤记录（高频查询） |
| idx_attendance_date | attendance_date | 普通索引 | 仪表盘近7天出勤趋势统计 |

### 3.7 score 成绩表

| 索引名 | 字段 | 索引类型 | 说明 |
|--------|------|----------|------|
| uk_student_course_exam | student_id, course_id, exam_type | 唯一索引 | 同一学生同一课程同一考试类型仅一条记录，重复录入时覆盖 |
| idx_course_id | course_id | 普通索引 | 按班级+课程查询成绩时联表 |
| idx_exam_date | exam_date | 普通索引 | 按考试日期范围筛选 |

### 3.8 homework 作业表

| 索引名 | 字段 | 索引类型 | 说明 |
|--------|------|----------|------|
| idx_class_id | class_id | 普通索引 | 查询某班级的所有作业列表 |

| idx_deadline | deadline | 普通索引 | 判断作业是否过期 |

### 3.9 homework_submission 作业提交表

| 索引名 | 字段 | 索引类型 | 说明 |

## 4. 设计说明

### 4.1 字符集选择

使用 `utf8mb4` 而非 `utf8`，前者支持完整的 Unicode 字符（包括 emoji 等四字节字符），后者只支持最多三字节。

### 4.2 存储引擎选择

使用 `InnoDB`，原因：
- 支持事务，保证数据一致性（如发布作业 + 批量创建提交记录应在同一事务中）
- 支持行级锁，并发性能好
- 支持外键（虽本次设计中未显式声明外键约束，由应用层保证数据完整性）

### 4.3 逻辑删除

所有表均使用 `is_deleted` 字段做逻辑删除：
- 删除操作统一为 `UPDATE ... SET is_deleted = 1`
- 所有查询均需加上 `WHERE is_deleted = 0`
- 联表查询时，被关联的表也需要同样的过滤条件

### 4.4 冗余字段说明

考勤表 `attendance` 中冗余了 `class_id` 字段。原因是：
- 学生可能中途转班，考勤记录需要保留打考勤时该学生实际所属的班级
- 若不冗余，学生转班后历史考勤记录的所属班级会被错误改变
