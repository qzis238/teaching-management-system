### 任务 13：创建公共模块（统一返回 + 统一异常 + 登录拦截器）

- **任务内容**：创建统一响应类 `Result<T>`（code、message、data）、业务异常类 `BusinessException`、全局异常处理器 `GlobalExceptionHandler`（捕获 BusinessException 返回业务错误，捕获其他异常返回 500）、登录拦截器 `LoginInterceptor`（校验 token，未登录返回 401）、跨域配置 `CorsConfig`。
- **涉及文件**：
  - [backend/.../common/Result.java](backend/src/main/java/com/mumululu/common/Result.java)
  - [backend/.../common/BusinessException.java](backend/src/main/java/com/mumululu/common/BusinessException.java)
  - [backend/.../common/GlobalExceptionHandler.java](backend/src/main/java/com/mumululu/common/GlobalExceptionHandler.java)
  - [backend/.../common/LoginInterceptor.java](backend/src/main/java/com/mumululu/common/LoginInterceptor.java)
  - [backend/.../common/CorsConfig.java](backend/src/main/java/com/mumululu/common/CorsConfig.java)
- **依赖**：任务 11（项目骨架）
- **验收点**：
  - [✓] 1/5 Result 类包含 code(int)、message(String)、data(T) 三个字段，提供静态成功/失败工厂方法
  - [✓] 2/5 BusinessException 包含 code 和 message 字段
  - [✓] 3/5 GlobalExceptionHandler 捕获 BusinessException → 返回对应 code 和 message；捕获 Exception → 返回 500
  - [✓] 4/5 LoginInterceptor 从请求头取 token，为空或无效时返回 401 JSON
  - [✓] 5/5 CorsConfig 允许跨域请求
- **验收标准**：写一个测试接口手动抛 BusinessException → 返回 JSON {"code":400,"message":"测试错误","data":null} → 未带 token 访问需要登录的接口 → 返回 401。

### 任务 14：实现登录相关接口

- **任务内容**：实现 `/api/login`、`/api/logout`、`/api/user/info` 三个接口。登录时验证用户名密码（BCrypt 比对），生成 JWT token 返回。退出时使 token 失效。user/info 从 token 中解析用户信息返回。
- **涉及文件**：
  - [backend/.../controller/LoginController.java](backend/src/main/java/com/mumululu/controller/LoginController.java)
  - [backend/.../service/UserService.java](backend/src/main/java/com/mumululu/service/UserService.java)
  - [backend/.../mapper/UserMapper.java](backend/src/main/java/com/mumululu/mapper/UserMapper.java)
  - [backend/.../entity/SysUser.java](backend/src/main/java/com/mumululu/entity/SysUser.java)
  - [backend/.../util/JwtUtil.java](backend/src/main/java/com/mumululu/util/JwtUtil.java)
- **依赖**：任务 12（数据库）、任务 13（公共模块）
- **验收点**：
  - [✓] 1/5 POST /api/login 正确用户名密码 → 返回 token 和用户信息
  - [✓] 2/5 POST /api/login 错误密码 → 返回 code=400 "用户名或密码错误"
  - [✓] 3/5 POST /api/login 连续 5 次失败 → 账号锁定，返回 code=400 "账号已被锁定"
  - [✓] 4/5 POST /api/logout → 返回成功，token 失效
  - [✓] 5/5 GET /api/user/info 带有效 token → 返回用户信息；无效 token → 返回 401
- **验收标准**：用 Postman 调 login → 拿到 token → 调 user/info → 拿到用户信息 → 调 logout → 再用原 token 调 user/info → 返回 401。

### 任务 15：实现仪表盘接口
