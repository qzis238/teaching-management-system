# 教学数字平台管理系统 — 接口文档

## 文档信息

| 项目 | 说明 |
|------|------|
| 接口前缀 | `/api/` |
| 请求格式 | application/json |
| 响应格式 | JSON |
| 文档版本 | v1.0 |

---

## 通用说明

### 统一返回格式

**成功响应：**

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

**失败响应：**

```json
{
  "code": 400,
  "message": "用户名或密码错误",
  "data": null
}
```

### 业务状态码

| code | 说明 |
|------|------|
| 200 | 请求成功 |
| 400 | 参数校验失败或业务逻辑错误 |
| 401 | 未登录或登录已过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 列表接口通用约定

**请求参数：**

| 参数 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| page | int | 否 | Query | 页码，默认 1 |
| pageSize | int | 否 | Query | 每页条数，默认 10 |

**返回格式：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "list": []
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| total | int | 符合条件的总记录数 |
| list | array | 当前页数据列表 |

## 1. 登录模块

### 1.1 登录

| 项目 | 说明 |
|------|------|
| 用途 | 用户使用用户名和密码登录系统 |
| 请求方式 | POST |
| 请求地址 | /api/login |

**请求参数（请求体 JSON）：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码（明文传输，后端加密比对） |

**成功响应：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userId": 1,
    "username": "admin",
    "realName": "管理员",
    "role": 1,
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

**失败响应：**

```json
{
  "code": 400,
  "message": "用户名或密码错误",
  "data": null
}
```

```json
{
  "code": 400,
  "message": "账号已被锁定，请15分钟后再试",
  "data": null
}
```

### 1.2 退出登录

## 6. 课程排课模块

### 6.1 获取班级课表

| 项目 | 说明 |
|------|------|
| 用途 | 获取指定班级的完整周课表（周一至周五，第1~8节） |
| 请求方式 | GET |
| 请求地址 | /api/schedule/{classId} |

**请求参数（Path）：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| classId | int | 是 | 班级ID |

**成功响应：**

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 10,
      "dayOfWeek": 1,
      "period": 1,
      "courseId": 1,
      "courseName": "高等数学",
      "teacherId": 2,
      "teacherName": "李老师"
    },
    {
      "id": 11,
      "dayOfWeek": 1,
      "period": 2,
      "courseId": 2,
      "courseName": "大学英语",
      "teacherId": 3,
      "teacherName": "王老师"
    }
  ]
}
```

> 返回该班级所有已排课程列表，前端按 dayOfWeek 和 period 渲染成 5×8 的课表表格。无排课的格子不存在对应数据。
