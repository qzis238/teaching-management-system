## 1. 登录模块

### 1.1 功能概述

用户通过用户名和密码登录系统，登录成功后才能访问系统内的所有功能页面。未登录用户访问任何页面时，系统自动跳转到登录页。

### 1.2 用户操作

| 操作 | 描述 |
|------|------|
| 登录 | 输入用户名和密码，点击"登录"按钮 |
| 退出登录 | 登录后在任何页面可点击"退出登录"返回登录页 |

### 1.3 业务规则

| 规则 | 说明 |
|------|------|
| 登录校验 | 用户名和密码必须与数据库中记录匹配 |
| 会话保持 | 登录成功后，一段时间内无需重复登录（具体时长可配置） |
| 密码安全 | 密码不允许明文存储，必须加密后保存到数据库 |

### 1.4 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 用户名或密码为空 | 前端阻止提交，提示"请输入用户名"或"请输入密码" |
| 用户名或密码错误 | 提示"用户名或密码错误"，不清空已输入的用户名 |
| 多次登录失败 | 连续 5 次失败后，账号锁定 15 分钟 |
| 未登录直接访问内部页面 | 自动跳转到登录页 |

## 2. 仪表盘模块

### 2.1 功能概述

登录后默认进入仪表盘首页。以统计卡片和图表的形式展示平台核心数据概况，让管理员快速掌握当前教学运营状态。

### 2.2 展示内容

**统计数字卡片（4 个）：**

| 卡片 | 数据来源 | 说明 |
|------|----------|------|
| 学生总数 | 学生表 | 当前系统中未删除的学生总人数 |
| 班级总数 | 班级表 | 当前系统中未删除的班级总数量 |
| 今日出勤率 | 考勤表 | 今日已打卡学生中"出勤"占应到人数的百分比 |
| 待批改作业数 | 作业提交表 | 学生已提交但老师尚未批改的作业份数 |

**图表（2 个）：**

| 图表 | 类型 | 说明 |
|------|------|------|
| 各班级学生人数分布图 | 柱状图 | X 轴为班级名称，Y 轴为学生人数，一目了然展示各班规模 |
| 近 7 天出勤趋势图 | 折线图 | X 轴为日期（含今天往前 7 天），Y 轴为出勤率，展示出勤变化趋势 |

### 2.3 业务规则

| 规则 | 说明 |
|------|------|
| 仪表盘数据只读 | 仪表盘仅做数据展示，不提供任何编辑入口 |
| 数据实时性 | 每次进入页面或手动刷新时重新查询最新数据 |
| 出勤率计算 | 出勤率 = 当日状态为"出勤"的人数 ÷ 当日应到总人数 × 100% |

### 2.4 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 系统中还没有任何学生/班级 | 统计卡片显示 0，图表显示"暂无数据" |
| 今天还没有任何考勤记录 | 今日出勤率显示为 0%，标注"今日暂无考勤记录" |
| 近 7 天内某天无数据 | 折线图中该点按 0 处理或虚线连接 |

## 3. 学生管理模块

### 3.1 功能概述

对学生信息进行增删改查管理。支持按姓名模糊搜索、按班级筛选、分页浏览，是整个平台的基础数据模块。

### 3.2 用户操作

| 操作 | 描述 |
|------|------|
| 查看列表 | 以分页表格形式浏览所有学生信息 |
| 搜索 | 在搜索框输入姓名关键字，按姓名模糊匹配 |
| 筛选 | 通过下拉框选择某个班级，只显示该班级下的学生 |
| 新增学生 | 点击新增按钮，弹出表单填写学生信息后保存 |
| 编辑学生 | 点击某行的编辑按钮，弹出表单修改学生信息后保存 |
| 删除学生 | 点击某行的删除按钮，确认后逻辑删除该学生 |
| 翻页 | 通过分页组件切换页码和每页条数 |

### 3.3 学生信息字段

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 姓名 | 学生真实姓名 | 是 |
| 学号 | 唯一标识，不可重复 | 是 |
| 性别 | 男 / 女 | 是 |
| 班级 | 下拉选择所属班级 | 是 |
| 手机号 | 11 位手机号码 | 否 |
| 家庭住址 | 文本输入 | 否 |

### 3.4 业务规则

| 规则 | 说明 |
|------|------|
| 学号唯一 | 系统中不能有两个相同学号的学生 |
| 一个学生只能属于一个班级 | 选择班级时只能单选 |
| 逻辑删除 | 删除学生时标记 is_deleted = 1，不从数据库物理删除 |
| 搜索和筛选可同时生效 | 既输入关键字又选择班级时，两个条件取交集 |
| 每页默认 10 条 | 可切换为 20 / 50 / 100 条 |

### 3.5 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 新增时学号已存在 | 提示"该学号已被占用，请更换" |
| 删除前该学生有未批改作业 | 提示"该学生还有 N 份作业未批改，确认删除吗？"，由用户决定 |
| 删除前该学生有考勤记录 | 考勤记录保留，学生标记为已删除 |
| 所选班级已被删除 | 该学生自动变为"未分配班级"状态 |
| 搜索无结果 | 表格显示"暂无数据"，不报错 |

## 4. 班级管理模块

### 4.1 功能概述

对班级信息进行增删改查管理。每个班级需要指定一名负责老师，班级是学生分组和排课的基本单位。

### 4.2 用户操作

| 操作 | 描述 |
|------|------|
| 查看列表 | 以分页表格形式浏览所有班级信息 |
| 新增班级 | 填写班级名称、选择负责老师后保存 |
| 编辑班级 | 修改班级名称或更换负责老师 |
| 删除班级 | 确认后逻辑删除该班级 |
| 搜索 | 按班级名称关键字搜索 |
| 翻页 | 通过分页组件切换页码 |

### 4.3 班级信息字段

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 班级名称 | 如"2024 级软件工程 1 班" | 是 |
| 负责老师 | 关联教师用户，下拉选择 | 是 |
| 班级描述 | 补充说明文本 | 否 |

### 4.4 业务规则

| 规则 | 说明 |
|------|------|
| 班级名称唯一 | 系统中不能有两个同名班级 |
| 每个班级必须指定负责老师 | 负责老师从系统已有教师用户中选择 |
| 逻辑删除 | 删除班级时标记 is_deleted = 1 |

### 4.5 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 删除前班级下有学生 | 阻止删除，提示"该班级下还有 N 名学生，请先将学生转出后再删除" |
| 删除前班级有已排课程 | 阻止删除，提示"该班级还有未完成的排课，请先清理排课数据" |
| 负责老师账号被删除 | 班级的负责老师字段置空，提示管理员重新分配 |
| 新增时班级名称重复 | 提示"该班级名称已存在" |

## 5. 课程排课模块

### 5.1 功能概述

为指定班级安排一周的课程表，以表格形式直观展示每周每天每节课的上课安排。每个格子显示课程名称和授课老师。

### 5.2 用户操作

| 操作 | 描述 |
|------|------|
| 选择班级 | 通过下拉框选择要查看/编辑课表的班级 |
| 查看课表 | 以周课表表格形式展示该班级一周课程 |
| 添加课程 | 在某个时间格中填入课程名称和授课老师 |
| 修改课程 | 修改某个时间格中的课程信息 |
| 删除课程 | 清空某个时间格中的课程安排 |
| 复制课表 | 将当前班级的课表复制到其他班级 |

### 5.3 课表结构

| 维度 | 内容 |
|------|------|
| 列（横向） | 周一 ～ 周五（5 列） |
| 行（纵向） | 第 1 节课 ～ 第 8 节课（8 行） |
| 每个格子 | 课程名称 + 授课老师 |

### 5.4 业务规则

| 规则 | 说明 |
|------|------|
| 同一班级同一时间不能有两门课 | 一个格子只能安排一门课程 |
| 同一老师同一时间不能给两个班上课 | 保存时校验老师时间冲突 |
| 课表按班级存储 | 每个班级独立一张课表 |

### 5.5 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 老师时间冲突 | 保存时提示"该老师在 XX 时间段已有其他课程安排" |
| 班级已被删除 | 该班级的课表数据同时标记删除 |
| 选择班级下拉为空 | 提示"请先创建班级"，引导用户去班级管理页面 |

## 6. 考勤打卡模块

### 6.1 功能概述

每天记录学生的出勤情况。支持按班级批量标记出勤状态，也支持按日期查看历史考勤记录。出勤状态分为四种：出勤、迟到、请假、缺勤。

### 6.2 用户操作

| 操作 | 描述 |
|------|------|
| 选择班级和日期 | 选择要打考的班级和日期，默认当天 |
| 批量打考勤 | 表格列出该班级所有学生，逐行选择出勤状态 |
| 快速标记 | 一键将全班学生标记为"出勤"，再对个别学生单独调整 |
| 查看考勤记录 | 按班级 + 日期范围查询历史考勤记录 |
| 修改考勤 | 对历史记录中的某条考勤进行修正 |
| 导出 | 将考勤数据导出为 Excel 文件 |

### 6.3 出勤状态

| 状态 | 说明 |
|------|------|
| 出勤 | 正常到校上课 |
| 迟到 | 晚于规定时间到校，但仍到校 |
| 请假 | 提前请假未到校 |
| 缺勤 | 未请假且未到校 |

### 6.4 业务规则

| 规则 | 说明 |
|------|------|
| 同一学生同一天只能有一条考勤记录 | 重复打考勤时覆盖旧记录 |
| 考勤按天按班级管理 | 每次操作以班级为单位 |
| 日期默认当天 | 允许补打历史日期的考勤 |

### 6.5 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 班级下没有学生 | 打考勤表格为空，提示"该班级暂无学生" |
| 所选日期是周末/节假日 | 正常允许打考勤（有些学校周末也有课），不做限制 |
| 部分学生漏打 | 保存时提醒"还有 N 名学生未标记出勤状态，是否继续保存？" |
| 学生已被删除 | 历史考勤记录保留，打考勤时列表中不显示已删除学生 |

## 7. 成绩管理模块

### 7.1 功能概述

老师录入学生各科考试成绩，支持按学生或按班级查看成绩数据。每门课程的成绩独立录入和管理。

### 7.2 用户操作

| 操作 | 描述 |
|------|------|
| 录入成绩 | 选择班级、课程、考试类型后，批量录入该班级所有学生的成绩 |
| 修改成绩 | 修改某条已录入的成绩 |
| 按学生查询 | 输入学生姓名或学号，查看该学生所有课程的成绩 |
| 按班级查询 | 选择班级和课程，查看该班级该课程的所有学生成绩 |
| 删除成绩 | 删除某条错误录入的成绩记录 |

### 7.3 成绩信息字段

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 学生 | 关联学生 | 是 |
| 课程 | 关联课程 | 是 |
| 考试类型 | 如"期中考试""期末考试""月考"等 | 是 |
| 分数 | 数值，如 0-150 或 0-100 | 是 |
| 考试日期 | 考试的具体日期 | 是 |

### 7.4 业务规则

| 规则 | 说明 |
|------|------|
| 同一学生同一课程同一考试类型只有一条记录 | 重复录入时覆盖旧成绩 |
| 分数范围校验 | 根据课程配置的满分值校验，如百分制 0-100 |
| 录入时批量操作 | 一次录入整个班级某门课的成绩 |

### 7.5 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 录入分数超出范围 | 前端阻止提交，提示"分数范围为 0 - XX" |
| 录入了负数 | 前端阻止提交，提示"分数不能为负数" |
| 学生已转班 | 历史成绩跟随学生，不受转班影响 |
| 课程或学生已被删除 | 历史成绩记录保留，查询时备注"数据已删除" |

## 8. 作业管理模块

### 8.1 功能概述

老师发布作业，学生（或代表学生的管理员）提交作业，老师对提交的作业进行批改和打分。涵盖作业的完整生命周期：发布 → 提交 → 批改。

### 8.2 用户操作

**老师端：**

| 操作 | 描述 |
|------|------|
| 发布作业 | 选择班级、课程，填写作业标题、内容描述、截止时间后发布 |
| 查看提交情况 | 查看某次作业全班学生的提交状态（已提交 / 未提交 / 迟交） |
| 批改打分 | 对已提交的作业打分并填写评语 |
| 删除作业 | 删除已发布的作业 |

**管理端（代替学生操作）：**

| 操作 | 描述 |
|------|------|
| 提交作业 | 标记某学生已完成作业提交 |
| 查看作业列表 | 查看所有已发布作业及提交状态 |

### 8.3 作业信息字段

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 作业标题 | 简要描述作业内容 | 是 |
| 作业描述 | 详细说明作业要求 | 是 |
| 所属班级 | 发布给哪个班级 | 是 |
| 所属课程 | 属于哪门课 | 是 |
| 截止时间 | 超过此时间提交视为迟交 | 是 |
| 满分 | 批改时的满分值，如 100 | 是 |

### 8.4 提交信息字段

| 字段 | 说明 |
|------|------|
| 学生 | 提交的学生 |
| 作业 | 关联的作业 |
| 提交状态 | 未提交 / 已提交 / 迟交 |
| 提交时间 | 实际提交的时间 |
| 得分 | 老师批改后的分数 |
| 评语 | 老师批改时的评语 |

### 8.5 业务规则

| 规则 | 说明 |
|------|------|
| 每个学生每次作业只有一次提交记录 | 不允许重复提交 |
| 迟交判定 | 提交时间晚于截止时间则为迟交 |
| 打分范围 | 得分不能超过作业设定的满分值 |
| 删除作业级联 | 删除作业时，关联的所有提交记录同步标记删除 |

### 8.6 特殊情况

| 场景 | 处理方式 |
|------|----------|
| 超过截止时间提交 | 标记为"迟交"，不阻止提交 |
| 批改时得分超过满分 | 阻止保存，提示"得分不能超过满分 XX 分" |
| 删除已有提交的作业 | 提示"该作业已有 N 名学生提交，确认删除？" |
| 班级下无学生时发布作业 | 正常发布，提交列表为空 |
| 学生被删除 | 该学生的提交记录保留，查询时标记"学生已删除" |

## 附录 — 全局通用规则

| 规则 | 说明 |
|------|------|
| 数据删除 | 全局使用逻辑删除（is_deleted），不做物理删除 |
| 必填校验 | 所有表单的前端和后端均需做必填字段校验 |
| 分页 | 所有列表类页面默认支持分页，每页默认 10 条 |
| 时间格式 | 统一使用 yyyy-MM-dd HH:mm:ss 格式 |
| 接口前缀 | 所有后端接口统一以 /api/ 开头 |
